#  Gestion de Livres

Une application web de gestion de livres avec authentification, conçue avec :

- Backend : Node.js + Express + MongoDB  
- Frontend : Angular (standalone components)  
- Authentification via JWT  
-  API REST pour gérer les livres (CRUD)

---

##  Fonctionnalités

-  Authentification (login,register)
-  Liste des livres
-  Ajouter un livre
-  Modifier un livre
-  Supprimer un livre
